Local test, not devnet

This section is the automated LiteSVM run in solana/tests/tests/lifecycle.rs. It is not a live market and it has no devnet transaction.

A split panel is escalated. The test split_vote_escalates submits Yes, No, Yes. The assertions are:

assert_eq!(market.status, verdict::Status::Escalated);
assert_eq!(market.votes[1].outcome, Outcome::No);

A disputed market is settled only by that market's escalation owner. The test dispute_posts_the_bond_and_the_escalation_owner_settles posts the bond, checks the status, then calls escalation_resolve as world.escalation. The assertions are:

assert_eq!(world.market(2).status, verdict::Status::Escalated);
assert_eq!(world.market(2).bond_lamports, BOND);
assert_eq!(world.market(2).status, verdict::Status::Final);
assert_eq!(world.market(2).final_outcome, Outcome::Yes);

The same file rejects anyone else. non_escalation_owner_cannot_resolve expects NotEscalationOwner and leaves the market Escalated. protocol_owner_cannot_resolve_a_market expects the same error when the protocol owner is not that market's escalation owner.
